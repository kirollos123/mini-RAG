# Mini-RAG

A production-oriented Retrieval-Augmented Generation (RAG) application built from scratch while following an educational series by **Abu Bakr Soliman**.

This repository documents my learning journey in designing, implementing, and deploying a modern AI-powered backend application using FastAPI and Large Language Models (LLMs).

> **Status:** 🚧 Work in Progress

---

## 📖 About the Project

Mini-RAG is an educational project that demonstrates how to build a production-ready Retrieval-Augmented Generation (RAG) system.

The goal is not only to generate answers with an LLM, but also to understand how modern AI applications are designed, implemented, and deployed in real-world environments.

Throughout this project, I will build every component step by step instead of copying the final implementation.

---

## 🎯 Learning Objectives

By completing this project, I aim to gain hands-on experience with:

* Backend development using FastAPI
* Building RESTful APIs
* File uploading and document processing
* Retrieval-Augmented Generation (RAG)

* Vector Databases
* PostgreSQL & MongoDB
* SQLAlchemy & Alembic

* Celery Background Workers
* Monitoring using Prometheus & Grafana
* Local and Cloud LLM Integration
* Production-ready project architecture
